Dismiss Continue Watching

About

Adds a dismiss button on each item in the Continue Watching section. Clicking it marks the item as watched, which removes it from Continue Watching.



Requirements

  • Jellyfin JavaScript Injector (required for the web UI button)
  • File Transformation (optional, recommended)


How it works

On hover, a close button appears on Continue Watching cards. The click calls Jellyfin's native PlayedItems API for the current user, then removes the card from the page.

Supported on Jellyfin Web and official apps that use the web UI. Pure third-party clients are not supported.
